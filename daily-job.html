Made for the daily job

Hands for the agent

An AI that only talks is an adviser. Daily work is spreadsheets, documents, slides and web pages.

One door for Office files

office-gateway is a single door for Word, Excel and PowerPoint. Behind it, every job goes to the engine that does it best: quick reads and edits to a command-line tool, heavy formula work to a calculation engine, delicate Excel edits through a lossless unpack-and-repack, slides rendered from HTML into real PowerPoint, Word files built directly from their XML format. The engines themselves come from open-source tools and skill packs; what I wrote is the part that decides which hand is safe for which job.

One door for the web

browser-gateway does the same for websites: four engines behind one door — one that clicks and types, 145 adapters that pull structured data from specific sites, read-only diagnostics, and custom scripts. Two lessons live in its comments. On 6 August I found I had described one engine wrongly — it is an installer and does not handle logins — and fixed it that day, because an AI agent believes whatever a tool says about itself. And a live browser is never shared: two agents typing into one tab corrupt each other’s work, so each one gets its own.

The hand I had to build myself

One job no ready-made engine did safely: change one number in a real workbook — full of formulas, charts and hidden sheets — without quietly breaking everything else. An agent asked to do it will often rewrite the whole file; it still opens, and it is still wrong. Sheet Shadow lets the agent edit a shadow copy first, shows the impact, writes only the parts that changed into a new file, and runs a final check for formula errors, damaged structure and changed macros before handing it back.

Routing decides which hand to use. Sheet Shadow is the hand I had to build myself.
