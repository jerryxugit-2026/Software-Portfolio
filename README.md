# Software Portfolio · Ziyang Xu

Four open-source tools — a study app with a registered software copyright, a Chrome
side panel for local AI agents, and two MCP servers (Sheet Shadow, PiMoa).

**▶ Live site: [jerryxugit-2026.github.io/Software-Portfolio](https://jerryxugit-2026.github.io/Software-Portfolio/)**

- [Ziyang Vocab Master](https://github.com/jerryxugit-2026/Build-Vocab-Master) — your own PDF becomes a study deck, browser-only.
- [DSH Browser Companion](https://github.com/jerryxugit-2026/dsh-web-companion) — the page you are reading, handed to a local AI agent.
- [Sheet Shadow](https://github.com/jerryxugit-2026/Build-Agent-Tools-PiMoa/tree/main/sheet_shadow) — agent-safe Excel editing (Go MCP server).
- [PiMoa](https://github.com/jerryxugit-2026/Build-Agent-Tools-PiMoa/tree/main/PiMoa) — a blind review panel of models, sandboxed (TypeScript MCP server).

This repository hosts the site source (`index.html` + `assets/`), served with GitHub Pages.
