The method

I build the measuring instrument first

Before arguing about what AI agents should be allowed to do, I build the layer that makes their work inspectable: a preview before a write, a sandbox before a verdict, a measurement instead of a claim. Three rules run through all four tools:

Local first

Your data never leaves your machine. The study app runs entirely in the browser, the side-panel agent runs on your own computer, and the review panel is sandboxed away from your disk.

A safety layer, not a promise

Agents are powerful and clumsy around real files. Every tool puts structure between intent and file: shadow models, targeted saves, delivery gates, blind review with evidence.

Measure, don't assert

When something broke, I instrumented it: 17.8× token amplification, 130-line citation drift, a 53-second failure — each found, fixed, and re-measured on a real audit.

01 · Study tool · registered software copyright

Ziyang Vocab Master

Study the words you actually meet, not someone else's list. Drop in your own textbook or exam-paper PDF: the extractor pulls candidate vocabulary and filters the noise, an AI factory enriches each word with IPA, definitions, roots, collocations and an image cue, and spaced-repetition flashcards drill it four ways — association, context, spelling and pronunciation.

02 · Chrome extension · local AI agent

DSH Browser Companion

An AI agent that sits next to the page you are reading. It reads the page for you — and when you turn that on, it works the page too: fills forms, translates while keeping the layout, summarises long documents, and collects the same thing across tabs. It runs on your own computer through DeepSeek Harness; nothing is sent to a third-party browser service.

03 · MCP server · Go-native

Sheet Shadow

An agent asked to edit a real workbook will happily rewrite the whole file. Sheet Shadow gives it a shadow model instead: inspect the workbook, preview the impact, apply semantic operations, then write only the touched parts into a new copy — with a delivery gate that scans for formula errors, package drift and macro changes before handoff.

04 · MCP server · mixture of agents

PiMoa

Give your coding agent a review panel: several models answer in blind parallel, one model synthesizes the verdict, and none of them can touch your disk. The server scouts the task boundary mechanically before any model starts, feeds code with real line numbers, and keeps verification strictly fail-closed.
